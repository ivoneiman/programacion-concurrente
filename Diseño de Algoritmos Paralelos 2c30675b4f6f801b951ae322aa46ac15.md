## Descomposición en tareas

- Se trata de definir un gran número de pequeñas tareas para obtener una descomposición de grano fino, para brindar la mayor flexibilidad a los algoritmos paralelos potenciales

![image.png](Dise%C3%B1o%20de%20Algoritmos%20Paralelos/image%203.png)

- Puede realizarse de muchos modos. Un primer concepto es pensar en tareas de igual código *(normalmente paralelismo de datos o dominio)* pero también podemos tener diferente código *(paralelismo funcional)*

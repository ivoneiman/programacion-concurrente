### Procesos que administran acceso a un recurso respetando orden de llegada

**Visto en la teoría como passing the baton, pero esta solución será una variante (ambas son válidas).**

![image.png](Exp%20P2/image.png)

**Sólo representar a los procesos que representen a los *escaladores*, y entre ellos administrarán el uso del recurso compartido (el paso).**

```pascal
Process Escalador[id: 0..29]
-- llega al paso
-- Solicita acceso al paso (Si está libre pasa, si no debe esperar)
// usa el paso con Exclusión Mutua
-- Libera el paso (Si hay algn esperando le cede el acceso, si no, lo libera)
```

```java
cola c; // Atención al comentario
sem espera[30] = ([30] 0); //para despertar estrictamente a 1 proceso en particular

// Al transferir el recurso este no se libera, simplemente se transfiere
//Entonces podemos usar este boolean para saber si podemos pasar o encolarnos 
boolean libre = true;
sem mutex = 1;

Process Escalador[id: 0..29]
{int aux;
-- llega al paso

P(mutex);
if (libre){
	libre = false 
	V(mutex); 
}//Al haber una dependencia entre las dos var se trabajan dentro de la misma SC
else {
	push (C,id);
	V(mutex); 
	P(espera[id]);
};

P(mutex);
if (empty(C)) libre = true // libero el recurso
else {
	pop(C,aux);
	V(espera[aux]); //despierto al siguiente
};
V(mutex);
```
